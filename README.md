# Hương Giang — Marketing Portfolio

Modern React + Vite + shadcn/ui portfolio for a Marketing Staff job search.
Pink + purple brand, recruiter-friendly sections, light/dark mode, and
animation-on-scroll for that fresh, active feel.

## Stack

- React 18 + TypeScript + Vite 5
- Tailwind CSS + tailwindcss-animate
- shadcn/ui (new-york style) — Button, Card, Badge, Input, Textarea, Label,
  Progress, Separator, Avatar, Tabs, Tooltip, Sheet
- Framer Motion for animations
- lucide-react icons
- react-intersection-observer for scroll reveals

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173.

## Build

```bash
npm run build
npm run preview
```

## Edit content

All copy lives in `src/data/portfolio.ts` — change one file, refresh.

## Drop in your CV

Save your CV as `public/cv.pdf` and the "Download CV" button works.

## Sections

1. Hero (name, role, CTAs, animated avatar)
2. About (bio + 4 highlight cards)
3. Stats (animated counters)
4. Skills (Hard/Soft/Tools tabs)
5. Experience (alternating timeline)
6. Selected Work (project case studies)
7. References (testimonial cards)
8. Education (degree + certifications)
9. Contact (info + form)
10. Footer
